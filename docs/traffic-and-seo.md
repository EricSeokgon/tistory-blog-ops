HadesYI는 글당 평균 조회수가 약 31회에 그칩니다. 이건 콘텐츠 품질 문제라기보다 **검색 결과에 아예 노출되지 않고 있다**는 신호입니다.

### 이미 확인된 것 (문제 없음)

- `robots.txt` 정상 — 글 페이지를 막는 규칙 없음. `/manage`, `/guestbook`, `/search`만 차단
- 사이트맵 존재 — `https://{블로그}.tistory.com/sitemap.xml` (티스토리 자동 생성)
- 블로그 공개 설정 정상

### 남은 가설

1. **검색엔진에 등록조차 안 돼 있다** ← 가장 유력
2. 도메인 신뢰도가 낮아 색인이 느리다
3. 발행 속도가 비정상적으로 빨라(2주에 10편) 저품질로 분류됐다

1번이 확인·해결되기 전에는 2·3번을 논할 수 없습니다.

## 할 일 (우선순위 순)

### 1. 구글 서치콘솔 등록

> 사용자가 **구글 계정에 로그인한 상태**여야 합니다. AI가 대신 로그인하지 않습니다.

1. https://search.google.com/search-console 접속
2. 속성 추가 → **URL 접두어** 선택 → `https://ericreview.tistory.com` 입력
3. 소유권 확인 → **HTML 태그** 방식 선택 → `<meta name="google-site-verification" content="...">` 복사
4. 티스토리 → 꾸미기 → **스킨 편집** → html 편집 → `<head>` 안에 붙여넣기 → 적용
5. 서치콘솔로 돌아와 **확인** 클릭
6. Sitemaps 메뉴 → `sitemap.xml` 제출
7. `hadesyi.tistory.com`에도 동일 반복

> 티스토리는 관리 → 플러그인에 **구글 서치콘솔 연동 플러그인**이 있는 경우가 있습니다. 있으면 스킨 편집 없이 처리됩니다.

### 2. 네이버 서치어드바이저 등록

한국어 블로그라면 네이버 유입이 큽니다. 반드시 하십시오.

1. https://searchadvisor.naver.com 접속 (네이버 로그인 필요)
2. 웹마스터도구 → 사이트 등록 → `https://ericreview.tistory.com`
3. 소유확인 → **HTML 태그** → 메타태그 복사 → 스킨 편집 `<head>`에 삽입 → 확인
4. 요청 → **사이트맵 제출** → `sitemap.xml`
5. 요청 → **RSS 제출** → `rss`
6. `hadesyi.tistory.com`에도 반복

### 3. 색인 요청 (대표글 우선)

등록만 하면 색인까지 몇 주 걸립니다. 주요 글은 수동으로 당기십시오.

- 구글: 서치콘솔 → **URL 검사** → 주소 입력 → 색인 생성 요청
- 네이버: 서치어드바이저 → 요청 → **웹 페이지 수집**

**우선 요청할 글:**

| 블로그 | 글 |
| --- | --- |
| 주식 한 입 | 96(자산배분), 100(적립식), 91(국내주식 세금), 64(미국주식 세금), 63(절세계좌) |
| HadesYI | 402(RAG 문서구조), 393·399·401(K8s 3부작), vLLM CUDA OOM |

신규 6편은 **공개로 전환한 뒤** 요청하십시오.

### 4. 온페이지 점검

- [ ] 각 글에 **대표 이미지** 설정 (현재 6편 모두 없음 — 검색 결과 썸네일과 SNS 카드에 영향)
- [ ] 블로그 설명(메타 디스크립션) 확인
- [ ] 글 주소 설정이 **숫자형**인지 문자열형인지 확인 (현재 ericreview는 숫자형)

### 5. 재측정

2~4주 뒤 `/manage/statistics/blog`에서 **검색 유입 채널 수치**를 다시 봅니다. 0에서 벗어났는지가 성공 판정 기준입니다.
