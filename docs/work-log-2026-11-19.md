## 5. 자동화 메모

- **marked.js를 CDN에서 에디터 페이지로 불러오는 방식이 이번 세션에서 차단**됐습니다. 대안: 셸에서 `marked@12.0.2`로 HTML을 만들어 임시 브랜치에 올리고, 에디터에서 커밋 SHA 고정 raw URL을 fetch → SHA-256 대조 → `setContent()`. 외부 스크립트 주입이 없어 더 단순합니다
- 임시 브랜치 `tmp-render`는 세션 프록시가 원격 브랜치 삭제를 받아 주지 않아 **남아 있습니다**(내용은 `/81`·`/318` 렌더 HTML뿐). GitHub에서 직접 지우면 됩니다
- 티스토리 본문·제목·발행/수정 시각은 **셸 curl로 읽을 수 있습니다**(`og:title`, `article:published_time`, `article:modified_time`). 브라우저 없이 전수 대조 가능
