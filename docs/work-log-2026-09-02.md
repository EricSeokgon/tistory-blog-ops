## 3. 제목 입력 — 백그라운드 탭에서 문자가 통째로 사라집니다

제목을 JS `focus()` 후 타이핑했더니 이렇게 들어갔습니다.

```
입력: 환전 수수료와 미국주식 실전 주문 — 우대환율·통합증거금·비용 총정리 (2026)
결과: 환전수수료와미국주식실전주문—우대환율·통합증거금·비용총정리
```

**공백과 괄호와 숫자가 전부 사라졌습니다.** `visibilityState`가 `hidden`인 탭이었습니다.

> ⚠️ **백그라운드 탭에서는 타이핑이 "일부만" 들어갑니다.** 앞서 기록한 "통째로 삼킨다"보다 더 나쁩니다 — **그럴듯하게 잘린 값이 남아** 검증을 안 하면 그대로 발행됩니다. GitHub 커밋 메시지에서도 같은 증상이 있었습니다.
>
> **해결:** 대상 필드를 **실제 마우스로 클릭** → `Ctrl+A` → `Delete` → 재입력 → **값 검증**. 클릭 한 번으로 탭이 활성화되면 그 뒤로는 정상입니다.
