## 5. 신규 절차 — GSC 필터는 URL 파라미터로 겁니다

지금까지 GSC 실적 보고서의 검색어·페이지 필터는 **메뉴를 클릭해서** 걸었고, 그 과정이 좌표 문제·Material 메뉴 문제로 가장 불안정한 구간이었습니다.

**URL 파라미터로 그냥 됩니다.**

```
https://search.google.com/search-console/performance/search-analytics
  ?resource_id=https%3A%2F%2Fhadesyi.tistory.com%2F
  &query=*kafka          ← 검색어 '포함' 필터
  &breakdown=page        ← 하단 표를 페이지 기준으로
```

```
  &page=*364             ← 특정 페이지로 필터
  &breakdown=query       ← 그 페이지의 검색어 분해
```

표는 JS로 그대로 읽힙니다.

```javascript
[...document.querySelectorAll('tr')]
  .map(r=>[...r.querySelectorAll('td,th')].map(c=>c.innerText.trim()).join(' | '))
  .filter(x=>x)
```

**클릭이 한 번도 필요 없습니다.** 원칙 9(좌표 금지)의 가장 좋은 형태입니다.
