## 3. 리디렉션 오류의 정체 — `/m/` 모바일 URL

76번 검사 화면에서 결정적인 단서가 나왔습니다.

```
참조 페이지: https://ericreview.tistory.com/m/75
크롤링에 사용된 에이전트: Googlebot 스마트폰
최근 크롤링: 2026. 7. 24.
페이지 가져오기: 실패: 리디렉션 오류
```

**Googlebot 스마트폰이 티스토리의 `/m/` 모바일 URL 경로로 글을 타고 들어가다가 리디렉션에서 걸렸습니다.** 12편이 한꺼번에 같은 오류를 낸 이유가 설명됩니다.

### 현재 상태 — 해소됨

직접 확인했습니다.

| 확인 | 결과 |
|---|---|
| `ericreview.tistory.com/68` | 200, 본문 1,890자 정상 |
| `ericreview.tistory.com/69` | 200, 본문 2,002자 정상 |
| `ericreview.tistory.com/m/69` | **200**, 본문 정상, `canonical = https://ericreview.tistory.com/69` |

`/m/` 경로가 리디렉션 없이 200을 주고 canonical도 데스크톱 URL로 제대로 잡혀 있습니다. 7월의 오류는 티스토리 쪽 일시적 상태였고 지금은 정상입니다.

> **다음에 리디렉션 오류가 재발하면 `/m/{id}` 를 먼저 열어보십시오.** 데스크톱 URL만 보면 원인을 못 찾습니다.

### 겸사겸사 확인된 것 — 얇은 글 문제

68·69의 본문이 **1,890자 / 2,002자**입니다. 신규 글(4,500자 이상)의 절반이 안 됩니다. GSC 개요에 **"색인이 생성되지 않은 페이지 164개"** 가 찍혀 있는데, 리디렉션과 별개로 **분량이 얇은 초기 글들이 상당수 포함**돼 있을 가능성이 큽니다. 리디렉션 대응이 끝났으니 다음 병목은 이쪽입니다.
